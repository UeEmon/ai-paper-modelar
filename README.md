# AI Paper Modelar / 汎用ペーパークラフトジェネレーター

AI Paper Modelarは、写真・スケッチ・公開資料・アイデアを参考に、紙模型のデザインを検討し、基本的な展開図を作成するWebアプリです。**鉄道模型ジオラマ専用ではありません。** 建築物、乗り物、風景、小物、キャラクター、オリジナル作品を制作ジャンルとして選択でき、鉄道模型は選択肢の一つとして引き続き利用できます。

## 初期実装

- Wikipedia日本語版で対象の名称を検索し、参考情報のURLを一覧表示。架空作品など検索結果がない場合も制作条件の入力を継続できます。
- OpenAI・Gemini・AnthropicのAPIを切替可能。APIキーはサーバー側環境変数に保持。未設定ならオフライン案を表示。
- 忠実再現、標準デフォルメ、アニメ風、昭和レトロ、簡単組立を選択。
- 縮尺は実寸1/1、1/12、1/24、1/35、1/48、1/72、1/100、鉄道模型向け1/150・1/160・1/80・1/87・1/220、任意1/1〜1/500。
- m・cm・mm単位で元の幅、奥行、高さを入力。建物型（壁・切妻／陸屋根）と汎用箱型（6面）の2種類の展開図をA4実寸PDF・SVGで生成。入力値は内部的にmへ換算するため既存プロジェクトと互換性があります。
- 50mm印刷チェック線、切断・折線・のりしろ表示、タイル分割。
- Docker Composeでローカル起動。
- 手持ち写真・設計図・PDF（JPEG/PNG/WebP/PDF）を最大8点アップロードし、サムネイルで確認・削除。資料ごとに方向とメモを付与。
- **利用者が明示的に許可した場合のみ**画像等のプレビューとPDF抽出テキストを選択中のAIプロバイダーに送信して文章案を作成。

## 起動方法

Docker Desktopを起動したら、リポジトリ直下で:

    cp .env.example .env
    docker compose up -d --build

ブラウザで http://localhost:8086 を開きます。API定義は http://localhost:8086/docs です。
停止コマンド:

    docker compose down

AI APIを使う場合は .env に AI_PROVIDER=openai と OPENAI_API_KEY=your-key などを設定してください。GeminiならAI_PROVIDER=gemini / GEMINI_API_KEY、AnthropicならAI_PROVIDER=anthropic / ANTHROPIC_API_KEYを使います。
モデル名は OPENAI_MODEL / GEMINI_MODEL / ANTHROPIC_MODEL で変更できます。APIキーをコミットしないでください。

## SenroLab 連携（展開図API）

SenroLab（Nゲージのレイアウト設計アプリ）の「再現してみた」で作った仮オブジェクトを、
`POST /v1/nets` で実寸の展開図（用紙ごとの SVG）にします。仕様は [docs/senrolab/](docs/senrolab/README.md)。

- 種類: トンネル・鉄橋・高架橋・駅舎・ホーム・建物・名所・山・水面・その他。駅舎・建物は切妻屋根の部品（app/generator.py）を用紙に詰めて並べ、用紙に収まらない大きさは箱形にします。
- 環境変数 `PAPERCRAFT_API_TOKEN` を設定すると `Authorization: Bearer <トークン>` を確かめます（SenroLab 側も同じ値）。
- `GET /health` で死活確認。
- イメージは CI が ghcr.io/ueemon/ai-paper-modelar に置きます（arm64）。main は `:main`、タグ `v*` は `:<版>` と `:stable`。

## 自分で撮影した写真・設計図・PDFの追加

1. 「YOUR REFERENCES」でファイルを選択（1件15MB以内、画面上で最大8件）。対応拡張子は .jpg / .jpeg / .png / .webp / .pdf。
2. 正面、背面、左右側面、屋根、平面図、細部などを選び、任意のメモを入力して追加します。
3. 画像やPDF1ページ目のサムネイルを確認して、不要なら「削除」。
4. AI連携を使う場合は「資料をAI提案にも利用する」に明示的にチェックを入れ、「AIで案を提案」を押します。

保存動作: 原本は保存しません。JPEGプレビューとPDF先頭5ページの抽出テキスト（最大6,000文字）のみメモリに保持し、1時間後に失効します。コンテナ再起動でも消去されます。ブラウザのタブを更新した場合は同じタブ内でアップロードIDを復元します。PDFのAI画像参照は先頭1ページのみ、AIへ渡す画像は最大3件で、それ以外はメタデータと抽出テキストを参照します。公開サーバーにデプロイする場合は先にログイン認証や所有者別データ隔離を実装してください。Docker Composeの既定設定はローカルホスト限定です。

PDFの寸法抽出、図面のトレース、写真からの正確な形状復元、OCR、原本アーカイブは将来の開発対象です。AI推定寸法を実測寸法として使用しないでください。API事業者側のデータ取扱いについても利用規約を確認してください。

## 実装上の制約

- 検索はWikipediaの概要情報に限られます。一次資料・実寸・立面図・構造図・著作権は未検証です。
- **写真・図面からの複雑な3D形状の自動復元、車・飛行機・人物など専用の立体展開アルゴリズム、画像AI生成はまだありません。**
- 現在の展開図は入力寸法に基づく**簡易建物／箱型の汎用テンプレート**です。ジャンルを「乗り物」「キャラクター」等に切り替えても、その題材に固有の複雑な形状は自動生成されません。AIは作り方の文章案を提案しますが、実物の寸法・造形再現は保証しません。
- スタイル切替は配色・窓の表示等の初期実装です。アニメ風の画像生成は次の段階です。
- 部品の接着構造は試作段階なので、接合検証・追加ののりしろ・組立説明書を改良する必要があります。
- PDFには英語部品名を使います。日本語フォントへの対応は今後行います。

## 制作プロジェクトの永続保存（v0.3）

Web画面の PROJECT LIBRARY でプロジェクトを作成・選択すると、制作メモ、制作ジャンル、基本形状、寸法単位、縮尺、寸法、屋根形状、デザイン設定を保存できます。後日開いたときに再読込できます。

- プロジェクト選択中のファイルアップロードは **原本を永続保存**します。対応形式はJPEG・PNG・WebP・PDF（1件15MB以内）。
- 原本、EXIFを除去したプレビュー、PDF先頭部分の抽出テキスト、資料の方向とメモを保存。1プロジェクト40件、最大100プロジェクト、原本合計1GBまで。
- 保存資料は画面からプレビュー・原本ダウンロード・メモ／方向の編集・削除・別プロジェクトへの複製ができます。
- 外部AIに利用する保存資料は各資料の「AI参照」を選択し、さらに従来の同意チェックを入れる必要があります。最大8件を指定でき、AIへの画像入力は先頭3件です。
- プロジェクト未選択時の一時資料は従来どおり1時間で失効します。既存の一時ファイルは自動では移行しません。

### Dockerの保存先

Composeの名前付きボリューム paper_modelar_data がコンテナの /data に接続されます。
データベースは /data/library.sqlite3、原本は /data/projects/<project-id>/files、プレビューは /data/projects/<project-id>/previews に保存します。
docker compose down やコンテナ再構築で資料は消えませんが、**docker compose down -v ではボリュームが削除されます**。重要資料は定期的にボリュームをバックアップしてください。

### 注意

本版はPC内の単独ユーザーを想定し、ホストの127.0.0.1でのみ公開する構成です。ログイン認証、個別ユーザー権限、暗号化保管、マルウェア検査は未実装です。インターネットに公開しないでください。
実在の図面の著作権や持ち出し許可、AI API事業者のデータ取り扱い条件を確認してご利用ください。
資料を保存しても、資料の題材を問わず正確な3D復元や図面の寸法認識を行うわけではありません。

## 汎用化と従来データの互換性

制作ジャンル（`subject_type`）は `architecture` / `vehicle` / `landscape` / `prop` / `character` / `original` / `railway` / `other` です。図面テンプレート（`template`）は `building` または `box` を指定します。寸法表示単位（`input_unit`）は `m`、`cm`、`mm` から選べ、APIの寸法値自体は従来どおりメートル換算です。以前の保存済みモデルやSenroLabの `/v1/nets` に渡すデータは、新規フィールド未指定なら従来の建物型として動作します。
縮尺を1/1として大きな建物を指定すると100ページ上限に達する場合があります。この場合は縮尺または元寸法を調整してください。
